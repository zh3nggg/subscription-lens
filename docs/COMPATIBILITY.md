## 复用原则

1. 优先复用统计引擎与回归测试；不嵌入另一个项目的完整网页，不启动额外的独立产品界面。
2. 固定上游提交，记录本地修改。代码及二进制发行同时保留许可证；关于页提供来源入口。
3. 底层账本替换必须先备份并校验来源覆盖，不能将新旧计数简单相加。
4. 平台专属功能按用户可完成的操作验收；Windows 托盘不宣称支持 macOS 菜单栏或 WidgetKit。
5. 用户已确定当前仅覆盖 Codex/OpenAI；其他供应商写入下一版展望，当前不作为已支持功能。

## 1.3 多供应商范围

已实现 CC Switch 请求日志只读接入、Claude Code/Gemini CLI 本地用量、JSONL 导入、供应商→模型分布图、Tokens/费用切换、请求筛选、CSV、自定义价格与性能统计。没有实现代理转发、供应商密钥切换或官方账单轮询；来源报告金额也不代表已核验发票。现代 Codex 计数引擎的接入状态保持不变。
